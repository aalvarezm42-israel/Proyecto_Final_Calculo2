# Proyecto Final - Cálculo 2: Método de Arandelas en 3D

Este repositorio contiene la implementación interactiva para el cálculo y la visualización de volúmenes de sólidos de revolución, desarrollado como proyecto final para el curso de Cálculo 2.

## Descripción del Proyecto
El código resuelve matemáticamente y grafica el volumen generado al rotar el área comprendida entre dos funciones alrededor del eje X, utilizando el **Método de Arandelas**. 

Como caso de estudio, se evalúan las funciones:
* Función exterior (Radio Mayor): g(x) = 2x
* Función interior (Radio Menor): f(x) = x^2

## Tecnologías Utilizadas
* **Lenguaje:** Python 3
* **Entorno:** Jupyter Notebook
* **Renderizado 3D Interactivo:** Plotly
